GNARLER

FunBox v3 + Daisy Seed · Stereo · MIDI · Expression · AI-generated

A full-wave-rectification octave-up fuzz that gets progressively more unstable as the Chaos knob rises. At low Chaos it's a punchy, harmonic octave-up fuzz; wind it up and it dissolves into glitchy, aliased, bitcrushed and wavefolded madness, with a chaos LFO ring-modulating the signal for extra instability. Three toggles pick the clip flavour, the chaos character (crush, fold, or both), and the octave voicing (sub, octave-up, or both). The right footswitch slams Chaos to maximum for instant destruction.

Signal Chain

Input → Noise Gate (KNOB 6) → Octave-up (full-wave rectify) + Sub-octave (flip-flop) blend (KNOB 5 / SW3) → Fuzz gain (KNOB 2) → Chaos ring-mod LFO (KNOB 4) → Clip (SW1: warm / fuzz / fold) → Chaos bitcrush / wavefold (KNOB 4 / SW2) → Tone LP (KNOB 3) → DC block → Level (KNOB 1) → safety limiter → stereo out.

Knobs

KnobFunctionBehavior
KNOB 1LevelOutput volume (0–2×).
KNOB 2FuzzGain into the clipper — light crunch fully left, full saturation fully right.
KNOB 3TonePost-clip low-pass filter. Dark (~400 Hz) fully left → open (~10 kHz) fully right.
KNOB 4ChaosThe headline knob. 0 = stable octave fuzz; turning up adds bitcrush, wavefold, and ring-mod instability until it's full glitch at max.
KNOB 5Oct MixOctave blend. Fully left = clean fuzz only; fully right = full octave-up (and sub level, per SW3).
KNOB 6GateNoise-gate threshold. Fully left = gate off; turning up gates harder to tame the chaos hiss between notes.

3-Position Toggles

SW1 — Clip Flavour

LeftWarm — soft-clip tanh overdrive. CenterFuzz — hard clip, aggressive. RightWaveFold — wavefolder for harmonically rich, synthy distortion.

SW2 — Chaos Character

LeftCrush only — Chaos adds bitcrush / sample-rate reduction. CenterFold only — Chaos adds sine wavefolding. RightCrush + Fold — both stacked for maximum destruction.

SW3 — Octave Mode

LeftSub only — blends in a square sub-octave (flip-flop), no octave-up boost. CenterOct-up only — full-wave-rectified octave-up voice. RightOct-up + Sub — both the octave-up and sub-octave voices together.

DIP Switches

Not used by GNARLER — all four DIPs are inert in this effect.

Expression Jack

Maps onto any knob via the heel/toe Set-Mode gesture (FS1+FS2 0.5 s). Suggested target: KNOB 4 (Chaos) for foot-swept destruction.

Usage tip: start with Chaos low, Oct Mix past noon, SW1 on Fuzz and SW3 on Oct-up for a classic octave fuzz. Then sweep Chaos up — or stomp FS2 — with SW2 on Crush+Fold for the full glitch meltdown. Use the Gate (KNOB 6) to clamp the noise between notes.

LEDs

  • LED 1: Bypass status (engaged).
  • LED 2: Chaos Spike active.

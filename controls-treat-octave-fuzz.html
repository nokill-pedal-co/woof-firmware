Treat Octave Fuzz

Terrarium + Daisy Seed · Mono

Sleigh Bells / "Treats"-inspired octave destroyer. Multi-octave layering (sub, dry, octave up, +2 octaves) slammed into iMic-style ADC hard clipping for that flat-topped, harsh, digital fuzz. Lo-Fi Drop footswitch instantly degrades to phone-speaker territory.

Knobs

KnobFunction
KNOB 1Volume (0× to 2×)
KNOB 2Slam (iMic clip gain 1× to 50×)
KNOB 3Tone (post-clip LP filter)
KNOB 4Sub (sub-octave voice level)
KNOB 5Dry (clean voice level — yes, you can solo any one voice)
KNOB 6Up (octave-up voice level)
iMic clipping: asymmetric hard clip with positive ceiling at 0.9 and negative floor at -1.0. Flat-topped, harsh, digital — modeled on the original iMic ADC behavior that made the "Treats" record sound the way it does.

Switches

SwitchFunction
SW1+2 Octaves (adds 2-octaves-up voice)
SW2Sub mode (mono divider / poly granular)
SW3Bit Crush (sample-rate reduction in addition to clipping)
SW4FS2 mode selector (momentary / latching for Lo-Fi Drop)

Footswitches

SwitchAction
FS1Bypass
FS2Lo-Fi Drop — bandpass filter + crush + bit reduce + 3× gain compensation. Tap or hold depending on SW4.

Treat Octave Fuzz

FunBox v3 + Daisy Seed · Stereo · MIDI · Expression

Octave fuzz with stereo-detuned sub and octave-up voices for chorus-like width on the octave stacking. iMic asymmetric hard clip preserved. Sub-octave detuned ±3¢ L/R; octave-up detuned ±3¢ reverse; dry stays centered.

Knobs

KnobFunction
KNOB 1Volume
KNOB 2Slam (iMic clip gain)
KNOB 3Tone
KNOB 4Sub level
KNOB 5Dry level
KNOB 6Up (octave-up level)

3-Position Toggles

SW1 — +2 Octaves & Sub Mode

CenterMono divider sub, no +2 octave. Left+2 octave voice on. RightPoly sub mode (granular pitch shift).

SW2 — Bit Crush

Center / RightOff. LeftBit crush on.

SW3 — Lo-Fi Flavor

CenterLo-Fi disabled (FS2 inert). LeftTape. RightDoom.

Footswitches

SwitchAction
FS1Bypass (fires on release).
FS2Lo-Fi Drop — tap = latch, hold = momentary.
FS1+FS20.5 s hold — Expression Set Mode.
FS1+FS22 s hold — clear expression mapping.
FS1+FS2at power-up — DFU bootloader.

MIDI

MessageMapping
CC 14–19Knobs 1–6 (with takeover).
CC 20Bypass (≥ 64 = bypassed).
CC 21Lo-Fi Drop (≥ 64 = active).

Expression Jack

Defaults unmapped — suggested target: KNOB 2 (Slam) for foot-controlled distortion intensity. Assign via FS1+FS2 0.5 s Set Mode.

Stereo

Sub-octave detuned −3¢ L / +3¢ R (in poly mode via per-channel grain rates, in mono mode via per-channel divider). Octave-up detuned +3¢ L / −3¢ R via fractional read-back delay (1024-sample ring buffer). Dry stays centered. Octave-up is rectified fabsf(dry) so each channel is DC-blocked after the detune read.

LEDs

  • LED 1: Lo-Fi active.
  • LED 2: Engaged.

Treat Octave Fuzz

Hothouse + Daisy Seed · Mono · 3-position toggles

Sleigh Bells / "Treats" inspired octave fuzz. POG-style multi-octave layering slammed into an iMic-style asymmetric hard clipper (pos 0.9, neg −1.0). Flat-topped, harsh, digital — NOT a soft-clip Padé tanh. Footswitches reversed from Terrarium.

Knobs

KnobFunction
KNOB 1Volume (0–2×)
KNOB 2Slam — iMic clip gain. THE distortion.
KNOB 3Tone (post-clip LP filter)
KNOB 4Sub level
KNOB 5Dry level (clean octave)
KNOB 6Up (octave-up level)

3-Position Toggles

TOGGLE 1 — +2 Octaves

Up+2 octave voice on. Middle/DownOff.

TOGGLE 2 — Sub Mode + Bit Crush

UpPoly sub (granular pitch shift), no bit crush. MiddleMono divider (zero-crossing), no bit crush. DownMono divider + bit crush.

TOGGLE 3 — Lo-Fi Flavor (FS2 mode)

UpTape — Lo-Fi Drop sounds vintage/warm. MiddleLo-Fi disabled — FS2 inert. DownDoom — Lo-Fi Drop sounds heavy/dark.

Footswitches (Hothouse convention)

SwitchAction
FS1 (left)Bypass.
FS2 (right)Lo-Fi Drop — tap = latch, hold = momentary. Bandpass + crush + bit reduce + 3× gain compensation.

LEDs

  • LED 1 (left): Engaged.
  • LED 2 (right): Lo-Fi active.

DFU

Hold FOOTSWITCH_1 for 2 s to enter the bootloader.
